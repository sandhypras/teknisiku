# Assets

Folder ini dipakai untuk menyimpan aset aplikasi Flutter.

## Struktur

- `images/`: foto atau gambar umum aplikasi
- `icons/`: ikon custom di luar Material Icons
- `logos/`: logo dan identitas brand Si Teknisi
- `illustrations/`: ilustrasi onboarding, empty state, dan error state
- `placeholders/`: gambar default untuk profil, layanan, atau dokumen demo

Daftarkan folder baru di `pubspec.yaml` jika menambahkan kategori aset baru.
